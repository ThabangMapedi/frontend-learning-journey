# Day 2: Terminal Commands

## Navigation
- pwd: Shows my current directory.
- ls: Lists files and folders.
- cd ..: Moves up one directory.
- cd ~: Goes to my home directory.

## File Management
- mkdir: Creates a directory.
- touch: Creates an empty file.
- cp: Copies a file.
- mv: Moves or renames a file.
- rm: Deletes a file.
- rmdir: Removes an empty directory.

## Git
- git status: Shows the state of my working tree.
- git add: Stages changes.
- git commit: Saves changes to Git history.
- git push: Uploads commits to GitHub.
- git log --oneline: Shows commit history.
